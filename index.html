驱动电机选型与功率匹配
教材第六篇§21.1 — 按最高车速确定电机额定功率（式21-15），按最高车速、爬坡、加速需求确定峰值功率，额定/峰值转矩匹配
⚡ 驱动电机功率需求估算
最高车速功率（式21-15）：P_v = (1/η_T) · [ M·g·f·v_max/3600 + C_D·A·v³_max/76140 ]，作为额定功率 P_e 的下限。
爬坡功率：P_i = (1/η_T) · [ M·g·(f·cosα + sinα)·v_i/3600 + C_D·A·v_i³/76140 ]，α = arctan(i_max)。
加速功率（工程常用估算式，按平均车速近似）：P_a = 1/(3600·t_a·η_T) · [ δ·M·v_a²/(2×3.6) + M·g·f·v_a·t_a/1.5 + C_D·A·v_a³·t_a/(21.15×2.5) ]，v_a = 100 km/h。
峰值功率 P_max ≥ max(P_v, P_i, P_a)。纯电动单级减速器 η_T ≈ 0.90～0.94；良好路面 f ≈ 0.013～0.018。

续驶里程与能量消耗
教材第六篇§21.2 — 续驶里程、百公里电耗、动力电池组数量校核（n₁按功率 / n₂按能量，取大者）
🔋 续驶里程估算
续驶里程 L = E_可用 / E_c × 100；E_可用 = E_电池 × SOC 可用系数。
百公里电耗 E_c 由学生按车型确定设计目标，下方等速电耗估算可作合理性校核；实际电耗须按相应工况试验方法验证。
🧮 等速行驶电耗估算（校核电耗目标）
等速行驶时电池端电耗 E_v = (M·g·f + C_D·A·v²/21.15) / (36·η_T·η_e·η_ec)，单位 kW·h/100km。
该式未计附件耗电、加减速及制动能量回收，只反映滚动与空气阻力消耗，作为电耗目标的下限参考。
自动引用：质量参数：汽车总质量
f、C_D、A、η_T 自动引用驱动电机选型页；η_e、η_ec 同时用于下方电池组数量校核。
🔌 动力电池组数量校核
按功率：n₁ = P_emax / (P_bmax·η_e·η_ec)；按能量：n₂ = 1000·W·L₀ / (C_s·U_s)，W = E_c/100（kW·h/km），L₀ 为目标续驶里程。
取 n₁、n₂ 中较大者并向上取整为电池组（模块）数目。教材式中 n₂ 未计可用 SOC；电池组总能量与上方 E_电池 应相互协调。

🔋 电驱动总成与动力电池布置要点

动力电池包

  • 优先平铺于前后轴之间的地板下，降低质心高度，并使前后轴荷接近设计目标。
  • 电池包底部为轴间最低点时，应校核最小离地间隙及纵向通过半径。
  • 侧面应留出碰撞变形空间（门槛梁吸能区），并布置防护底板及密封、热管理管路。

电驱动总成

  • 电机、减速器、控制器常集成为电驱动桥，布置于前舱或后轴附近，取消纵向传动轴。
  • 高压线束应远离碰撞变形区，充电口、DC/DC、车载充电机布置需便于维护。
  • 前舱无发动机时可布置储物空间，但需兼顾正面碰撞吸能结构长度。

📋 设计规范检查清单
  • ⬜外廓尺寸符合 GB 1589-2016 规定的最大限值
  • ⬜轴距与车型级别对应的参考范围相符（教材表1-4）
  • ⬜总质量不超过 GB 1589-2016 规定的最大限值
  • ⬜轴荷分配在该车型要求范围内（教材表1-9）
  • ⬜驱动电机额定功率满足最高车速需求（式21-15）
  • ⬜峰值功率满足最高车速、爬坡、加速功率需求；λ = P_max/P_e 在常用范围
  • ⬜电机最高转速对应车速不低于设计最高车速；计算爬坡度、加速时间满足目标
  • ⬜续驶里程满足目标；电耗目标不低于等速电耗估算
  • ⬜电池组数量按 n₁（功率）、n₂（能量）取大者，总能量与设定值协调
  • ⬜动力电池包布置满足离地间隙、侧碰吸能空间和轴荷分配要求
  • ⬜最小转弯直径在参考范围内（教材表1-17）
  • ⬜轮胎负荷系数在 0.85~1.00 范围内
  • ⬜轮胎速度等级允许最高速度超过整车最高车速
  • ⬜H点位置符合 SAE J1517 推荐曲线范围
  • ⬜头部空间满足 SAE J1052 要求
  • ⬜运动学校核通过（转向轮、驱动半轴、悬架与电池包无干涉）
